# Personal Portfolio Website

Source code for the personal portfolio published through GitHub Pages at:

[https://mudassirabbasi1.github.io](https://mudassirabbasi1.github.io)

## Purpose

The site presents Mudassir Ahmed's developer profile, selected projects, technical skills, and contact information in a portfolio format.

## Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages

## Run Locally

```bash
git clone https://github.com/mudassirabbasi1/mudassirabbasi1.github.io.git
cd mudassirabbasi1.github.io
```

Open `index.html` in your browser.

## Deployment

Changes pushed to the `main` branch are served by GitHub Pages.
